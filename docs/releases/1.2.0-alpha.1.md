# QuestCalibrator Alpha 1.2

Prerelease for testing, based on the `alpha` branch.

## Changes

- Guided calibration with wrist-mounted tracker, headset-mounted tracker, and
  Index-to-visor motion demos, plus replay and pause controls.
- Clearer calibration results and recovery messages, with Fast, Slow, and Very slow
  duration choices.
- Fix jump confirmation counting repeated observations from one device as agreement
  from multiple devices.
- Improve continuous correction timing, transform updates, and recovery after
  tracking changes. Add the Legacy continuous-calibration option.
- Improve protected-chaperone and field-anchor handling, profile persistence,
  SteamVR startup behavior, and VR keyboard input.
- Add diagnostic exports and opt-in updates for verified stable-release packages.

## Installation

Download `QuestCalibrator-1.2.0-alpha.1.zip`, extract it, and close Steam completely,
including its system-tray process. Run the included `Install.ps1` with PowerShell
and follow `README-INSTALL.txt`. Restart SteamVR after installation.

Update the overlay and driver together: this build uses IPC protocol 9. Disable
other Space Calibrator drivers to avoid applying calibration twice.

This prerelease is excluded from stable automatic updates. Playspace scale solving
remains experimental. Clean-install, upgrade, uninstall, and hardware regression
testing across supported setups are not yet complete.

## Validation

The regression suite covers 192 scenarios, including three tests that reproduced
the duplicate-device confirmation bug. Release preparation also checks the native
build, project analysis, duplicate detection, embedded motion assets, and package
contents.
